Sistema operativo:
Es el software que administra el hardware y permite ejecutar programas. En Codespaces se utiliza Linux.

Node.js:
Es un entorno de ejecución que permite ejecutar JavaScript fuera del navegador y crear servidores.

Aplicación server.js:
Es el archivo donde se programa el comportamiento del servidor y las rutas que responderá.

Puerto:
Es el punto de comunicación por donde el servidor recibe solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros de eventos y actividades del servidor. Ayudan a identificar errores y monitorear el funcionamiento del sistema.
